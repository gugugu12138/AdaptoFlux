Controlled scaling of the unmodified ATF graph executor on pure scalar CPU operators. DAG depth is fixed at 8 and width varies from 4 to 128, corresponding to 32–1024 operation nodes and 68–2176 edges; batch size is 32. Every operation has two inputs and performs the same 16 bounded residual-tanh updates. (a) Native serial and four-thread end-to-end execution, including per-call graph preparation and, for parallel execution, thread-pool lifecycle. (b) Separate graph construction, declared-type compatibility and topological-order passes. The declared-type pass calls PathGenerator._is_type_compatible; it is an auxiliary benchmark, not an existing full compiler validator. (c) Speedup is the median of paired serial/parallel timing ratios. Points summarize five independent graph seeds, each using two warmups and seven timed repetitions; error bars show the min–max across per-graph medians and are not confidence intervals. Node and edge counts covary, so this experiment does not isolate edge density. For this scalar CPU workload, median four-thread speedup is below 1 at every tested size.
